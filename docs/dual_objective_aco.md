# 时间—风险双目标疏散路线管控（dual_objective_aco）

## 文献依据

杨天鹏, 肖建强, 严兴旭, 等. 复杂建筑火灾环境下双目标疏散路径规划研究[J]. 防灾减灾学报, 2026, 42(3): 40-50. DOI: 10.13693/j.cnki.cn21-1573.2026.03.005.

论文将建筑火灾风险与疏散时间同时作为目标，核心模型为：

```text
BLD = P / C                                      (1)
R_f = f_t + f_co + f_vi                          (2)
R_r = R_f * BLD / l                              (3)
min R(x) = sum R_ij * x_ij                       (5)
min T(x) = sum d_ij / v_ij(t) * x_ij             (6)
D_ij = L_ij / M_ij                               (当量距离)
```

其中 `R_f` 是火灾风险，`BLD` 是建筑/人员负荷，`l` 是距火源距离，`R_r` 是路线风险，`T` 是疏散时间，`v_ij(t)` 是随时间变化的区域速度。论文采用改进蚁群算法进行双目标寻优。

## 本平台中的实现

本策略在网页选择的 A 地图上运行，不读取任何监控文件，也不添加虚构的摄像头或检测结果：

1. **地图来源**：只读取当前选择的 A 地图 JSON；网格、墙体、障碍物、出口和区域语义均来自该地图。
2. **区域速度**：复用平台既有的烟雾浓度调速规则。烟雾浓度的恐慌响应峰值在 0.5 附近，浓度高于 0.65 后进入毒性减速，最低保持基准速度的 20%；浓度高于 0.9 的格点视为不可通行。速度不是另外编造的固定表。
3. **风险场**：平台没有 FDS 温度、CO、能见度场时，使用真实 `smoke_matrix` 作为 `R_f` 的代理；局部人数与出口数量近似 `BLD`；到烟源/烟雾区域的距离近似 `l`。有烟源对象时用烟源坐标，没有烟源对象时从真实烟雾矩阵的多源距离推导。最终风险场归一化到 `[0,1]`，不会把烟雾冒充成温度或 CO。
4. **双目标比较**：对每个人的所有可达出口分别计算完整路径，比较论文式 (5)(6) 的加权目标，而不是只看“最近出口”：

   ```text
   cost = (1 - w) * T + w * risk_scale * R
   ```

   `w=0` 为最短时间优先，`w=1` 为最低风险优先，`w=0.5` 为时间—风险折中。
5. **路线执行**：计算出的下一个路点同时写入 C 的 `route_next_cell`，并设置 `strict_route=true`。B 的元胞自动机优先让人员走向该路点；路点被占用时最多等待 3 步，偏离后用相邻路径格重新接回，避免“只画线、不按线走”。
6. **重规划**：默认每 30 秒重规划一次；烟雾速度场发生实质变化时也会重新计算。可在网页设置风险权重和重规划间隔。
7. **图表输出**：运行目录输出 `dual_objective_routes_<地图名>_initial.png/json` 和 `..._final.png/json`，并复制一份到外层 `outputs/figures`。网页“规划路线”图层读取 `c_runtime.dual_routes` 实时绘制。

## 算法说明与边界

论文的完整求解器是改进蚁群算法。本平台为了交互式运行和结果可复现，使用**确定性的 Pareto 加权最短路径**在同一栅格、同一风险场和同一烟雾速度场上求解：对每个出口只运行一次多目标 Dijkstra，同时得到所有人员到该出口的代价和父节点，再比较各出口的完整路径。这样避免“每个人、每个出口各跑一次 A*”造成的性能爆炸。保留的是论文的双目标定义、火灾风险项、当量/时间代价和 Pareto 折中思想；没有声称复现论文的蚁群信息素迭代细节。`risk_scale=12` 和 `density_radius_m=2` 是平台把风险折算到时间量纲、把局部负荷离散到栅格的工程参数，不是论文原文参数；论文的蚁群参数（α=1、β=10、ρ=0.5、Q=150、200 次迭代）记录在源码注释和文献中，未在本实时求解器中假装执行。

如果后续接入真实的温度、CO、能见度场，风险项应替换为论文式 (2) 的 `f_t + f_co + f_vi`；当前版本不会在缺少这些数据时生成假值。

## 使用方式

命令行：

```bash
python main.py --strategy dual_objective_aco --map maps/examples/simple_room.json   --risk-weight 0.5 --dual-replan-interval-s 30 --social on --visual off --report off
```

网页：

1. 在“C10 管控策略”选择“时间—风险双目标管控（杨天鹏）”。
2. 设置风险权重 `w` 和重规划间隔。
3. 点击开始运行；“规划路线”图层显示当前计算的路径，人员按路点移动。
4. 运行目录和 `outputs/figures` 中可查看初始/最终路径图。

## 与另外两种策略的区别

| 策略 | 目标 | 主要约束 | 人员行为 |
|---|---|---|---|
| `none` | 无集中路线管控，仅 B 的局部行为与 C 的常规信息/引导 | 局部元胞规则 | 不读取规划路点 |
| `fire_aware` | 一个综合策略内同时编排出口关闭、区域封锁、分区疏散、火灾感知路线管控 | 出口可用性、封锁区、分区软偏好、火灾等效距离 | 由火灾感知路由器设置目标出口，路线权重影响移动 |
| `vision_astar` | 时间优先的地图 A* | 所选 A 地图、烟雾调速、可通行性 | 严格沿时间最优路点移动 |
| `dual_objective_aco` | 时间与火灾风险同时优化 | 所选 A 地图、烟雾调速、风险场、所有可达出口比较 | 严格沿 Pareto 折中路线移动 |

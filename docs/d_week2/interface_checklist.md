# D 端接口联调检查清单

本清单用于记录 D 端接收 A、B、C 输出时需要核对的字段和规则。状态含义如下：

- **已在演示原型验证**：仅在前端演示数据和演示导出中完成结构或一致性验证，不代表真实模块已经接入；
- **待团队确认**：字段含义、坐标、索引、单位或责任边界尚未冻结；
- **待真实联调**：当前格式已有草案，但仍需使用 A、B、C 的真实输出验证。

## A → D

| 字段或规则 | D 侧检查内容 | 状态 | 说明 |
|---|---|---|---|
| `grid_width` | 正整数，能够确定画布和场数据宽度 | 待真实联调 | 演示场景有固定网格宽度，尚未读取 A 的真实输出 |
| `grid_height` | 正整数，能够确定画布和场数据高度 | 待真实联调 | 演示场景有固定网格高度，尚未读取 A 的真实输出 |
| `cell_size` | 正数，单位为米 | 待真实联调 | 原型默认值为 `0.5 m`，仍需与 A 的场景数据对接 |
| `cell_type` | 枚举值合法，数组尺寸与网格一致 | 待真实联调 | 枚举已形成草案，真实地图内容尚未接入 |
| `exits` | 出口编号、位置和初始化信息完整 | 待真实联调 | 原型仅使用演示出口 |
| `smoke_sources` | 烟雾源编号、位置和启动信息完整 | 待真实联调 | 原型仅使用演示烟源 |
| 坐标原点和 `x`/`y` 方向 | 明确原点、轴方向及展示映射 | 待团队确认 | 当前文档仍有不同表述 |
| 二维数组索引顺序 | 明确第一维和第二维分别对应的坐标 | 待团队确认 | 当前不固定 `[x][y]` 或“`y` 行 `x` 列” |

## B → D

| 字段或对象 | D 侧检查内容 | 状态 | 说明 |
|---|---|---|---|

| `time_s` | 满足 `time_s = step * time_step` | 已在演示原型验证 | 已用 `step=720`、`time_step=0.5`、`time_s=360` 验证 |
| `people` | 数组长度与页面场景人数一致 | 已在演示原型验证 | 演示测试中页面人数和导出数量均为 180 |
| `heading` | 使用约定枚举并由 B 直接输出 | 待真实联调 | 原型只生成演示朝向，尚未读取 B 输出 |
| `target_exit` | 出口编号能够关联初始化出口 | 待真实联调 | 原型只生成演示目标出口 |
| `evacuated` | 布尔值；已撤离人员持续输出 | 已在演示原型验证 | 页面 175 人已疏散时，导出中正好有 175 个 `true` |
| `risk` | 个体风险值类型和含义一致 | 待真实联调 | 当前仅有演示值 |
| `dose` | 个体累计暴露剂量类型和单位一致 | 待真实联调 | 当前仅有演示值 |
| `exits.queue_length` | 非负整数，出口编号有效 | 待真实联调 | 当前仅有演示队列长度 |
| `smoke_field` | 二维浮点数组，数值在 0～1 | 已在演示原型验证 | 已验证演示导出的结构和范围，B 的真实烟雾场待接入 |
| `risk_field` | 二维浮点数组及其单位、阈值和范围 | 待团队确认 | 由 B 计算并输出，最终口径尚未冻结 |
| `congestion_field` | 元胞邻域行人密度二维数组，数值在 0～1 | 已在演示原型验证 | 页面与导出使用同一归一化口径 |
| `events` | 事件类型、步数、人员和位置字段完整 | 待真实联调 | 当前只有少量演示事件 |

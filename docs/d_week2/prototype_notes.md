# 行人疏散仿真平台交互原型说明

## 1. 原型定位

本原型用于验证行人疏散仿真平台的界面布局、交互流程和数据接口，包括场景切换、图层显示、运行控制、指标展示和结果导出。

当前页面采用前端演示数据，人物运动、烟雾、拥堵、曲线和指标均由浏览器中的演示逻辑生成。原型尚未接入 A、B、C 模块的真实模型，不代表真实元胞自动机、烟雾扩散或社会信息传播仿真结果。

## 2. 已实现功能

- 提供教学楼、开放大厅、商场局部三个示例场景；
- 支持 2D 和 2.5D 视图切换；
- 支持行人、烟雾、拥堵、路径和社会关系图层显示；
- 支持开始、暂停、单步、重置和运行速度控制；
- 支持场景人数、随机种子、时间步长、元胞尺寸等参数；
- 提供烟雾风险、社会信息和疏散策略相关开关；
- 展示疏散人数—时间曲线、出口利用率、风险与拥堵指标和实验日志；
- 支持导出演示配置 JSON 和符合当前草案结构的标准快照 JSON。

## 3. 当前统一参数

| 参数 | 当前值或规则 |
|---|---|
| `time_step` | 默认 `0.5 s` |
| `cell_size` | 默认 `0.5 m` |
| `smoke_field` | 使用 0～1 归一化表示 |
| `congestion_field` | 使用 0～1 归一化表示 |
| `schema_version` | `0.1-draft` |

二维场数组的索引顺序仍待团队确认，原型和示例只验证数组结构，不宣称索引规则已经冻结。

## 4. 数据一致性验证

以下结果来自当前前端演示原型的实际测试，不是 A、B、C 真实模型的联调结果：

| 检查项 | 实际结果 |
|---|---|
| 场景人数 | 180 |
| 导出 `people` 数量 | 180 |
| `person_id` | 1～180，无重复 |
| 页面已疏散人数 | 175 |
| 导出 `evacuated=true` 数量 | 175 |
| `congestion_field` 范围 | 0～0.213 |
| 时间换算 | `step=720`、`time_step=0.5`、`time_s=360`，满足 `time_s = step * time_step` |

页面统计、内部人员状态和导出快照使用同一套演示疏散人数与拥堵归一化口径。

## 5. 输出文件

- `d_snapshot_demo.json`：演示用标准快照 JSON，顶层结构与 `schema_version=0.1-draft` 对齐；
- `evacuation_demo_config.json`：当前页面参数的演示配置 JSON。

两个文件均属于前端演示输出，不应作为真实实验结果使用。

## 实测结果

2026-08-30 使用正式输入完成了两次真实端到端 E0：

- 输入为 `maps/edited_map.json`、`control/output_people_position.json`、`control/config_template.yaml`。
- 两次均在 158 step、79.0 s 模拟时间完成 40/40 撤离；首次撤离 20.5 s，平均疏散时间 53.775 s，T90 为 68.0 s。
- 同一 random seed 的两轮 `people_log.csv` 与 `event_log.csv` 完全一致。
- 后端平均单步约 104 ms；CSV、metrics、疏散曲线、累计占用热力图、Week-6 指标和结果 ZIP 均由真实数据生成。
- 旧 B 版本仍有 135 个 step 出现活动人员重叠，单步最多 8 个重叠元胞、单元胞最多 3 人。D 仅检测和展示，不修改冲突算法。
- 当前 `edited_map.json` 不含 `smoke_source`，所以 E0 是无烟基线。独立有烟接口已验证为地图 `smoke_source` 到 B `smoke_matrix[y][x]` 再到 D 显示。
